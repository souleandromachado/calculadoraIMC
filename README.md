# 🧮 Calculadora de IMC

Uma aplicação web simples, moderna e responsiva para calcular o Índice de Massa Corporal (IMC), desenvolvida utilizando **HTML5**, **CSS3** e **JavaScript** puro (Vanilla JS).

## 🚀 Demonstração

A aplicação conta com uma interface em formato de *card* centralizado e fornece feedback visual instantâneo mudando de cor conforme o resultado da classificação do IMC.

## 📋 Funcionalidades

- Entrada de dados com validação para peso (kg) e altura (m).
- Cálculo instantâneo do IMC ao clicar no botão.
- Classificação automática baseada nos parâmetros inseridos.
- Estilização dinâmica por cores para facilitar a leitura do resultado:
  - 🔵 **Magreza** (Menor que 18,5 kg/m²)
  - 🟢 **Normal** (Entre 18,5 e 24,9 kg/m²)
  - 🟠 **Sobrepeso** (Entre 24,9 e 30 kg/m²)
  - 🔴 **Obesidade** (Maior que 30 kg/m²)

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página.
* **CSS3:** Design responsivo, estilização moderna e transições suaves.
* **JavaScript (ES6):** Lógica de cálculo, validação de inputs e manipulação do DOM para exibição dos resultados.
